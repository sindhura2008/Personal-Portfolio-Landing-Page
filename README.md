# Sindhura Sadhu - Personal Portfolio Landing Page

A responsive one-page portfolio built with semantic HTML5 and CSS (Flexbox and Grid).

**Live site:** file:///C:/Users/Sindhura/Downloads/Sindhura%20Sadhu%20-%20Portfolio%20Preview.html

## Files
- `index.html` - page structure (header, nav, main, sections, footer)
- `style.css` - styles, layout and responsive rules
- `images/profile.svg` - profile avatar

## Design decision I am proud of
I used CSS Grid with `repeat(auto-fit, minmax(240px, 1fr))` for the skill and project cards, so they rearrange themselves from one column on phones to several columns on desktop without extra code.
